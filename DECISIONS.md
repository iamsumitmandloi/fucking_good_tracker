8. **Study "Browse the bank" chips** (Source tab counts) are in the design but not in PRD scope. Build the chips with live counts plus a simple read-only list per source; no editing.
9. **Flutter toolchain = fvm default (Flutter 3.47.9, Dart 3.13.7).** `flutter` on PATH resolves to `~/fvm/default/bin/flutter`. *Superseded by 10.*
10. **Toolchain moved to plain Flutter 3.50.0 stable (Dart 3.14.0), no fvm.** The second machine has no fvm; its global Flutter was upgraded to 3.50.0, which satisfies `pubspec.lock` (flutter ≥ 3.47.0, dart ≥ 3.13.7). Use `flutter`/`dart`, not `fvm flutter`. `pubspec.lock` re-resolved under it (`meta` 1.19.0, `listen` 1.0.1); kept.
11. **Imports moved from `package:flutter/material.dart` to `package:material_ui/material_ui.dart`.** Flutter 3.50 deprecates the former (analyzer: "deprecated after v3.47.0-0.0.pre. Use package:material_ui/material_ui.dart"), giving 19 infos. `material_ui` 1.11.1 is the official flutter/packages library and was already a transitive dependency; promoted to direct with `flutter pub add material_ui`. Chosen over silencing the lint.
12. **Quick-log grammar additions (found while writing the ≥30 parser tests).** `+`/`&` join items paid together, `,`/`;`/new line separate entries, so "1 cig + tea 45, lunch 130" splits ₹45 inside the `+` group only. A trailing whole number 1–5 without ₹/rs after cig/tea is a count ("tea 2" = 2 teas). A bare trailing `HH:MM` (colon only) is a time ("tea 16:30"; "zomato 12.50" stays money). Sleep/wake accept a bare hour ("woke 6"). "<text> lunch <amount>" is a meal ("canteen lunch 130"), but text before a meal word without an amount stays a note ("After lunch"). A weight outside 20–300 kg is a note, not a spend. A comma inside a number ("8,000 steps") does not split.
13. **Today tiles show "—" when nothing is logged today, cigarettes included** (CLAUDE.md rule 9). The tile is dashed only when the metric was never logged at all (DESIGN.md QuickTile).
14. **Quick log writes nothing itself.** The sheet returns the events; Today logs them, so one 6 s undo covers the whole batch.
15. **Repeat a usual = the 5 most frequent labels in the last 14 days** (PRD §3.2), excluding `study`, `note`, `void`. Ties go to the most recent. The design's "Weight" chip has no label, so it only shows up if a labelled weight exists. Tapping a chip adds that entry (last amount/category) to the preview, not to the text.
16. **Tile taps that can't be +1:** meal opens Quick log prefilled by time of day (breakfast < 11, lunch < 16, snack < 19, dinner); protein opens Quick log with "protein "; supplements open a checklist (tick = log, untick = undo today's entry). Long-press on any tile opens Quick log.
17. **Bus card copy has no direction.** Events don't say office or home, so it reads "Reached 10:40" (design: "Reached office 10:40"); the second leg reads "On the bus home" / "Home 19:28". A leg that crosses midnight is not paired (legs pair within one date); rare for this commute, noted in the test.
18. **Time chips are 44 tall, not the design's 40** (touch-target rule). A picked time later than now means yesterday, same as a typed one.
19. **`DEV_IDS` build flag.** `--dart-define=DEV_IDS=true` makes `newEventId()` return `dev-<uuid>`, so the owner's live phase checks write only rows that stats ignore (CLAUDE.md rule 3). Normal builds are unchanged.
20. **Today refreshes Study Bank + Start Here when the cache is older than 6 h** (same rule as the Study tab), so the Up-next card fills on first launch without visiting Study.

21. **Legacy columns are matched by header pattern, not exact name** (no live read yet). Lower-cased letters/digits; first match wins. Daily Summary: date = `date`/`day`; cigarettes `cig`|`smok`; sleep hours `sleep`; weight `weight`|`wt`|`kg`; steps `step`; water `water` (≤ 10 = litres); energy `energy`; commute `commute`|`bus`|`travel`. Spending: date; amount `amount`|`amt`|`inr`|`cost`|`price`|`spent`; time; category `category`|`cat`|`type`|`bucket`; item `item`|`what`|`description`|`details`|`merchant`|`note`; method `method`|`paid`|`via`|`mode`|`source`|`payment` (contains "lazy" → source lazypay). Timeline: date, time, text `entry`|`event`|`what`|`activity`|`log`|`note`|`text`. Dates accept ISO, d/M/yyyy, "16 Nov 2026", "Mon 16 Nov". Unknown shapes are skipped, never thrown. To be checked against the owner's live read.

The Events tab wins per (date, metric); legacy spend is used only on days with no money in Events. Legacy events have `legacy-` ids, are never written to the outbox, and never feed Today's tiles.

## Phase 7: read-only viewer (handoff_v2, 18 Nov)
38. **One flag for every write path: `FeatureFlags.logging`** (`lib/core/feature_flags.dart`, default off, `--dart-define=LOGGING=true` turns it on). Off: `EventsRepository.log/undo` throw `ReadOnlyError`, `SyncService.flush` returns `blocked` and keeps the outbox (an older build's queue is never sent), and the router has no `/today`, `/study`, `/bus`, `/session`, so the tiles, Quick log, FAB, bus card, Study and Bus mode are unreachable. On: Today is the first tab and Study the last (7 tabs), and every v1 path works as before (its tests run with the flag on).
39. **Events is the only source.** Refresh fetches `tabs=Events` only. The legacy adapter and repository stay in the code, unused by the viewer. The v1 Week/Money screens (legacy-merged) are not in the shell any more; they are kept and still tested on test-only routes (`extraRoutes`), not deleted.
40. **Viewer data rules** (`lib/domain/viewer/`): drop `test-`/`dev-` ids, apply voids; money only from `spend` rows; day-to-day excludes `bills`/`one_off`; a night belongs to its wake date (bed ≥ 12:00 → wake next day); averages are over days that have data; untimed rows count in totals and appear under "Logged without a time", never on a time axis; notes only in the Day list.
41. **The week is the 7 days ending today (IST)**, as in v1. On 18 Nov that is Thu 12 – Wed 18. The Day tab opens on today (an empty-state card until something is logged) and ‹ goes back to the first day with data; › stops at today. Tapping a Week row opens that day.
42. **Day KPIs compare with the 7 days ending on the shown day** (mean over days with data). For 17 Nov these equal the week figures in the design.
43. **Definitions the brief left open:** tea pairing and timed counts sum `qty`; an "order" is one (date, time) group, so the 5 untimed quick-commerce lines of 11 Nov are one order (6 orders, as the design says); pay-later merchants are the first word of the label before ":" (Zepto, Blink, Zomato); one-offs are named by the text after ":" ("Developer registration fee"); breakfast protein = a meal/snack row with unit `g` (v1 rule); the outlier card needs ≥ 5 timed nights and a bedtime > 1.5 SD from the mean; usual bedtime is rounded to 15 min (00:43 → "about 00:45"); hour histogram starts earlier than 06 if a cigarette is timed before 06:00.
44. **Insight confidence 4–5** ("≥ 21 days with a consistent direction") is implemented as 4 from 21 days and 5 from 42, but no card claims a consistent direction yet, so the app shows at most 3 dots.
45. **Charts are CustomPainters/plain widgets; no fl_chart, no new packages.** Data colours are a `SeriesColors` ThemeExtension. Bar charts keep the average tag in a right gutter so it never covers a value label (in the design it can overlap the last bar's label).
46. **Untimed payments on the Day tab are one chip** ("13 payments · ₹893"), not one chip each, so 11 Nov stays readable.
47. **Dev-only `--dart-define=TODAY=2026-11-17`** pins the clock (23:00 IST that day) so the screens can be compared with the design files; `/trends?seg=sleep` opens Sleep & body. Both used for the screenshots in PROGRESS.
48. **`app/tool/export_events.dart`** (GET `tabs=Events` only) writes `app/fixtures/events_backfill.json` (gitignored). The 7.2 tests and one widget test assert the brief's table on it and skip with a message when it is absent.

## 2026-11-25 (Sheet-as-source-of-truth alignment)

49. **Sleep windows fall back to `sleep.end_time` when no `wake` row follows.** All 14 live `sleep` rows populate `end_time`, while 9 of 14 have no separate `wake` event. `sleepWindows()` checks for a closing `wake` event first (within 18 h), then falls back to `sleep.endTime` (`wakeDate = date` when `time < end_time`, else `date + 1`).
50. **Daily `steps` = `MAX`, not `SUM` (`daily_stats.dart`).** Both `Today` (`G8`) and `Daily Review` (`E5`) compute daily steps with `MAXIFS`, because cumulative Google Fit / daily step entries supersede earlier estimates.
51. **Live `SpendCategory` and read-only `EventType.activity` (`event_type.dart`).** Added `food_out`, `food_delivery`, `quick_commerce`, `drinks`, `personal_care`, `smoking`, `entertainment`, `health`, and `SpendCategory.deliveryLike` (`{delivery, food_delivery, quick_commerce}`) for `burn.dart`, plus `EventType.activity` as a read-only enum value so sheet reads retain rows like `movie-20261121-1840-2300`.
52. **`Start Here` `Target date` month-name format (`cells.dart`).** `cellDate()` supports `d MMMM yyyy` / `d MMM yyyy` (e.g. `"30 November 2026"`) in addition to ISO and `d/M/yyyy`.
53. **Default supplements & alias matching (`settings_repository.dart`, `daily_stats.dart`).** Seeded default `AppSettings.supplements` to `['Vitamin D3 + K2', 'Vitamin B-complex', 'Omega-3', 'Ashwagandha']`, with `supplementKey()` canonical matching for sheet label variants (e.g. `"Vitamin D3 and K2"`, `"Neurokind (vitamin B)"`) and case-insensitive protein unit `g`.
54. **Overnight bus arrives (`commute.dart`).** Early-morning `< 04:00` `bus_arrive` events pair with an open `bus_board` on the prior day.
55. **`ParseResult.toEvents()` + `km` exercise + bus destination notes (`parser.dart`).** Added `toEvents()` helper (separate paired `spend` row), `km` exercise unit support, and `to office`/`home` bus notes while preserving `build_events.dart` and legacy keyword categories.
