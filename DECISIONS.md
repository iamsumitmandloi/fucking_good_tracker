Format: date · what · why · evidence.

## 2026-11-17

1. **Repo layout: docs stay in `handoff/`, app goes to `app/`.** The brief expects `PRD.md`, `design/`, `backend/` at the root; they live in `handoff/`. Moving them gains nothing. The pre-existing `fucking_good_tracker/` (default counter app) is left untouched and unused. Evidence: `ls` of the repo root.
2. **`fucking_good_tracker/shit` holds the live `/exec` URL and what looks like the token in plain text.** Added to `.gitignore`; should be deleted once `secrets.json` exists. Value never copied anywhere.
3. **Bus mode summary copy changed.** Design says "Written to Study Sessions as one row"; PRD §4 says each card is its own `study` event and the summary writes nothing extra. PRD wins. New copy: "Each card is saved as its own entry. Blank and Shaky come back tomorrow; Nailed in 4 days." Evidence: `BusMode.dc.html:79` vs `PRD.md:69`.
4. **Bus mode run size.** The design shows a 4-segment progress bar; the due queue can be 198 cards on day 1. A run takes the first N due cards (Settings, default 10); segments = N. Exit keeps rated cards.
5. **Week cigarette bar colour.** Design colours Mon/Tue lime (4 each) and other days grey; budget is 5. Rule: lime when ≤ budget, grey otherwise. Evidence: `Trends.dc.html:105`.
6. **Sleep row label = wake date.** Design's "Tu" row is 22:30 → 06:00 ending Tue morning, matching Today's "Slept ~22:30 → ~06:00". Evidence: `Trends.dc.html:106`, `Today.dc.html:125`.
7. **"Day N" in the Today header** = days since the first date with any data (11 Nov = Day 1, 17 Nov = Day 7). Evidence: `Today.dc.html:24`.
8. **Study "Browse the bank" chips** (Source tab counts) are in the design but not in PRD scope. Build the chips with live counts plus a simple read-only list per source; no editing.
9. **Flutter toolchain = fvm default (Flutter 3.47.9, Dart 3.13.7).** `flutter` on PATH resolves to `~/fvm/default/bin/flutter`. *Superseded by 10.*
10. **Toolchain moved to plain Flutter 3.50.0 stable (Dart 3.14.0), no fvm.** The second machine has no fvm; its global Flutter was upgraded to 3.50.0, which satisfies `pubspec.lock` (flutter ≥ 3.47.0, dart ≥ 3.13.7). Use `flutter`/`dart`, not `fvm flutter`. `pubspec.lock` re-resolved under it (`meta` 1.19.0, `listen` 1.0.1); kept.
11. **Imports moved from `package:flutter/material.dart` to `package:material_ui/material_ui.dart`.** Flutter 3.50 deprecates the former (analyzer: "deprecated after v3.47.0-0.0.pre. Use package:material_ui/material_ui.dart"), giving 19 infos. `material_ui` 1.11.1 is the official flutter/packages library and was already a transitive dependency; promoted to direct with `flutter pub add material_ui`. Chosen over silencing the lint.
12. **Quick-log grammar additions (found while writing the ≥30 parser tests).** `+`/`&` join items paid together, `,`/`;`/new line separate entries, so "1 cig + tea 45, lunch 130" splits ₹45 inside the `+` group only. A trailing whole number 1–5 without ₹/rs after cig/tea is a count ("tea 2" = 2 teas). A bare trailing `HH:MM` (colon only) is a time ("tea 16:30"; "zomato 12.50" stays money). Sleep/wake accept a bare hour ("woke 6"). "<text> lunch <amount>" is a meal ("canteen lunch 130"), but text before a meal word without an amount stays a note ("After lunch"). A weight outside 20–300 kg is a note, not a spend. A comma inside a number ("8,000 steps") does not split.
13. **Today tiles show "—" when nothing is logged today, cigarettes included** (CLAUDE.md rule 9). The tile is dashed only when the metric was never logged at all (DESIGN.md QuickTile).
14. **Quick log writes nothing itself.** The sheet returns the events; Today logs them, so one 6 s undo covers the whole batch.
15. **Repeat a usual = the 5 most frequent labels in the last 14 days** (PRD §3.2), excluding `study`, `note`, `void`. Ties go to the most recent. The design's "Weight" chip has no label, so it only shows up if a labelled weight exists. Tapping a chip adds that entry (last amount/category) to the preview, not to the text.
16. **Tile taps that can't be +1:** meal opens Quick log prefilled by time of day (breakfast < 11, lunch < 16, snack < 19, dinner); protein opens Quick log with "protein "; supplements open a checklist (tick = log, untick = undo today's entry). Long-press on any tile opens Quick log.
17. **Bus card copy has no direction.** Events don't say office or home, so it reads "Reached 10:40" (design: "Reached office 10:40"); the second leg reads "On the bus home" / "Home 19:28". A leg that crosses midnight is not paired (legs pair within one date); rare for this commute, noted in the test.
18. **Time chips are 44 tall, not the design's 40** (touch-target rule). A picked time later than now means yesterday, same as a typed one.
19. **`DEV_IDS` build flag.** `--dart-define=DEV_IDS=true` makes `newEventId()` return `dev-<uuid>`, so the owner's live phase checks write only rows that stats ignore (CLAUDE.md rule 3). Normal builds are unchanged.
20. **Today refreshes Study Bank + Start Here when the cache is older than 6 h** (same rule as the Study tab), so the Up-next card fills on first launch without visiting Study.

21. **Legacy columns are matched by header pattern, not exact name** (no live read yet). Lower-cased letters/digits; first match wins. Daily Summary: date = `date`/`day`; cigarettes `cig`|`smok`; sleep hours `sleep`; weight `weight`|`wt`|`kg`; steps `step`; water `water` (≤ 10 = litres); energy `energy`; commute `commute`|`bus`|`travel`. Spending: date; amount `amount`|`amt`|`inr`|`cost`|`price`|`spent`; time; category `category`|`cat`|`type`|`bucket`; item `item`|`what`|`description`|`details`|`merchant`|`note`; method `method`|`paid`|`via`|`mode`|`source`|`payment` (contains "lazy" → source lazypay). Timeline: date, time, text `entry`|`event`|`what`|`activity`|`log`|`note`|`text`. Dates accept ISO, d/M/yyyy, "16 Nov 2026", "Mon 16 Nov". Unknown shapes are skipped, never thrown. To be checked against the owner's live read.
22. **Each legacy tab feeds one thing, so nothing is counted twice.** Daily Summary → cigarettes, weight, steps, water, energy (synthetic events, no money) and sleep hours for nights without bed/wake times. Spending → spend events (category from the Category column, else keyword guess). Timeline → only `sleep`/`wake` phrases via the Quick-log parser (a stated time later than the row's time = the day before). The Events tab wins per (date, metric); legacy spend is used only on days with no money in Events. Legacy events have `legacy-` ids, are never written to the outbox, and never feed Today's tiles.
23. **Data bugs are flagged, not fixed** (PRD §6.4). A commute number in another column's text that disagrees with the Commute column, and a steps number in another column when the Steps column is empty, show in a "Sheet data to check" card on Week. Stats use only the column values.
24. **Week and Money cover the 7 days ending today** (rolling, "Wed 11 – Tue 17 Nov" in the design), not a calendar week.
25. **Not-logged card** adds Weight to the design's Water / Bkfst protein / Energy / Steps rows; Study sessions shows a count. Orange when 0.
26. **Money copy.** The middle legend keeps the design's "Canteen, tea, singles, street food". "Still owed" under Pay later is dropped (no repayment data); it reads "N charges this week." Smoking est. = this week's cigarettes × price × 30 / 7.
27. **Charts are plain widgets plus one CustomPainter** (weight). fl_chart was optional in the PRD and is not added.
28. **Today's "Day N" counts from the first date in Events or the legacy tabs** (DECISIONS 7 expects 11 Nov = Day 1, which lives in the legacy tabs).
